# Multimodal diagnostic notes

The official three literature baselines are run with their native belief assumptions. A separate multimodal panel should not silently replace those assumptions with an invented mixture controller. For Arcari, multimodality can be represented as structural/model modes only when the same nominal digital-twin model set is available to all methods. For KH and TV-GP-LCB, multimodality is an assumption-stress test rather than a like-for-like method extension.
